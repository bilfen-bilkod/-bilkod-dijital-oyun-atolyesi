Yeni Oyun Ekle

Tek formu doldurun, GitHub hesabınızla onaylayın. Ayrı JSON dosyası indirmeniz veya site kodu değiştirmeniz gerekmez.

Yalnızca 3 adım:
  1. Oyunun adını ve GitHub / GitHub Pages bağlantısını buraya girin.
  2. GitHub'da Onayla ve Yayınla düğmesine basın. Açılan GitHub sayfasında bilgileri kontrol edip Submit new issue düğmesini seçin.
  3. GitHub otomasyonu listeyi günceller; GitHub Pages başarılı şekilde yayımladığında oyun atölyede görünür.

Güvenlik: Yayınlama yetkisi sadece bilfen-bilkod GitHub hesabındadır. Bu sayfa şifrenizi veya erişim anahtarınızı istemez.

Oyunun Bilgileri

GitHub depo bağlantısını veya Settings → Pages adresini de yapıştırabilirsiniz; sistem oyun bağlantısına dönüştürür.
Görselin internette herkese açık bir adresi olmalı. Dosya yükleme bu sürümde yoktur.

Bu işlem GitHub'da son onay gerektirir. Yalnızca bu formu doldurmak oyunu yayınlamaz. Yayınlama GitHub Pages çalışmasına bağlıdır.

GitHub yayınlama formu açıldı.

GitHub sayfasında oyun bilgilerini kontrol ederek Submit new issue düğmesine basın. Yeni sekme açılmadıysa GitHub onay sayfasını buradan açın.
