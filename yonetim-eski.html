Tek Formla Oyun Yayınla

Yeni oyun eklemek için aşağıdaki bağlantıyı açın. GitHub hesabınızla giriş yaptıktan sonra oyun adını, bağlantısını, kategorisini ve açıklamasını doldurup Submit new issue düğmesine basın. Yalnızca yetkili bilfen-bilkod hesabının gönderimleri otomatik işlenir. İşlem tamamlanınca oyun, GitHub Pages güncellemesiyle ana sayfada görünür.

Listeyi GitHub'da Yayınla

Yeni oyunları ekledikten sonra aşağıdaki düğmeye basın. İndirilen oyunlar.json dosyasını sitenizin GitHub deposundaki aynı adlı dosyanın üzerine yükleyin.

3 adımda yayınlama:
  1. Oyunu GitHub Pages üzerinde yayınlayıp adresini yukarıya yapıştırın.
  2. Buradan oyunlar.json dosyasını indirin.
  3. GitHub'daki BİLKOD portalı deposunda eski oyunlar.json dosyasını yeni dosyayla değiştirin ve commit edin.
GitHub Pages yayınlaması tamamlanınca oyun, okul ve evde aynı sitede görünecektir.
